Engineering principles

1. Learn the underlying computer science.
2. Implement important algorithms from scratch.
3. Build reusable modules.
4. Test everything.
5. Separate experiments from production code.
6. Never commit API keys or credentials.
7. Prefer reproducible environments.
8. Document assumptions and interfaces.
9. Measure performance.
10. Build progressively from fundamentals to systems.

Project goal

The goal is not simply to collect AI examples.

The goal is to build a complete computer-science-to-AI engineering foundation where each level builds on the previous one.
